# 🚀 Nishu Kumari | Developer Portfolio

A modern, responsive personal portfolio website built with **React.js**, showcasing my technical skills, projects, education, achievements, certifications, and experience.

## ✨ Features

- 🖥️ Responsive single-page portfolio
- 🎨 Modern and clean user interface
- 🌙 Dark and light theme support
- 👩‍💻 Personal introduction and technical skills
- 🎓 Education and academic background
- 🏆 Achievements and certifications
- 💼 Experience and mentorship
- 🚀 Featured projects with GitHub links
- 📄 Resume access through Google Drive
- 📬 Contact section with social media links

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nishuiiitbh/Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

### 5. Create a production build

```bash
npm run build
```

## 🌐 Deployment

This portfolio is configured for deployment as a **Render Static Site**.

- Build Command: `npm run build`
- Publish Directory: `build`
